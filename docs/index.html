产品介绍

商品图片，不该一张张手动保存

电商详情页的图片分散在轮播、详情长图、懒加载模块和背景样式中，格式与尺寸各不相同。图提取帮你一次性收拢，统一输出。

图片分散，逐个保存太慢

主图、细节图、详情长图散落在页面各处，还有大量懒加载图片。图提取自动扫描当前页面，把能拿到的商品图一次找全。

格式五花八门，用起来不便

页面里的图片可能是 JPG、WebP、GIF 或 AVIF。下载时统一转换为 PNG，免去格式转换和二次处理的麻烦。

批量处理，节省重复劳动

全选、反选、按需勾选，一次下载几十张商品图，文件名自动按 001、002 编号，整理商品素材更省心。

核心功能

把「提取图片」这件事做到顺手

从扫描、过滤、预览到下载，每一步都为电商运营和设计同学的日常场景设计。

一键提取

自动扫描页面所有商品图片，兼容懒加载、srcset、data-src 与背景图，无需手动滚动找图。

智能过滤

自动排除图标、logo、1×1 像素、占位图与小于 100×100 的装饰图片，只保留真正的商品素材。

集中预览

在新标签页中以响应式网格展示全部图片，支持缩略图、尺寸信息、格式标签与大图预览。

自由勾选

支持全选、反选与单张勾选，已选数量实时显示，按需下载，不必把整页图片都存下来。

统一 PNG

JPG、WebP、GIF 等格式通过 Canvas 自动转换为 PNG，保留清晰度，方便直接用于设计稿与素材库。

批量下载

逐张显示转换进度，完成后给出成功与失败反馈。文件按「商品图_001.png」自动编号，整理更轻松。

安装步骤

四步装好，马上开始提取

图提取完全在本地运行，无需注册或登录。按下面的步骤加载到 Chrome 即可。

  1. 01

    下载并解压插件

    下载插件压缩包，解压到本地一个容易找到的文件夹。

    下载 imagegrab.zip
  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入下面的地址并回车：

    chrome://extensions
  3. 03

    开启开发者模式

    打开扩展管理页右上角的「开发者模式」开关。

    开关变为蓝色即表示已开启
  4. 04

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择解压后包含 manifest.json 的 extension 文件夹。

    安装完成后，打开任意商品详情页右下角即可看到按钮

使用小提示

  • 支持淘宝 / 天猫、京东、拼多多商家版的商品详情页。
  • 首次提取前可先滚动页面，让懒加载图片完成加载。
  • 若下载失败，可能是图片域名不在授权范围内或受防盗链限制。
  • 插件更新后，在扩展管理页点击刷新按钮即可生效。
